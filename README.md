# 裂罅循环助手

Warframe 裂罅 Mod（国服：裂隙振幅晶体）循环助手。贴一张循环界面的截图，选好想要的词条，网站会列出下一步所有可走的路线：每次成功率、预计循环次数、全程赤毒（平均、中位、90% 把握），选哪条由你决定。每循环一次再贴一次截图，它会告诉你保留新的还是旧的，并重新计算。

- 四种语言：简体中文（国际服，默认）、国服、繁體中文、English，术语全部取自游戏字典
- 可以设多组目标（满足任意一组即可），比如「伤害 + 多重 + 腐蚀/病毒」或「多重 + 暴伤 + 弹药效率/异常状态伤害」
- 目标可以直接打字：「基多射 负任意」「腐蚀或病毒」「多重110」「3+1」，认不出的部分会标出来
- 词条范围页：同类武器比不同词条分布，或同一词条分布比不同类武器；点属性名输入数值即可看浮动系数
- 武器图片来自官方 Public Export CDN
- 截图识别在浏览器里完成，图片不会上传
- 路线由动态规划求出最省赤毒（或最省次数）的走法，分布由模拟得出

## 开发

需要 Node.js 26。

```bash
npm install
npm run dev      # 本地开发
npm test         # 单元测试
npm run build    # 生产构建（GitHub Pages 由 .github/workflows/deploy.yml 自动构建）
```

## 目录

- `src/engine/` 公式、可出词条、求解器（`solver.ts`）及测试
- `src/ocr/` 截图识别（PaddleOCR PP-OCRv6 tiny，Apache-2.0）和解析
- `src/ui/` 界面
- `public/models/` 识别模型

玩家自制，与 Digital Extremes 无关。
